# ZESTWARE | Premium Streetwear Store

ZESTWARE is a high-end, production-ready e-commerce platform for modern apparel and streetwear. Built with a focus on premium aesthetics, speed, and a seamless user experience for both customers and administrators.

[ZESTWARE | Premium Streetwear](https://zestware.onrender.com/)

## 🚀 Features

### Customer Experience
- **Premium Collection View**: Minimalist product grid focusing on high-quality visuals.
- **Dynamic Product Details**: Detailed view with image galleries, smooth transitions, and size selection.
- **Smart Cart System**: Responsive quantity management and subtotal calculations.
- **Secure Checkout**: Streamlined billing details and UPI-integrated payment flow.
- **Order Tracking**: Personalized order history for authenticated users.

### Admin Dashboard
- **Product Management**: Full CRUD (Create, Read, Update, Delete) with multi-image upload support.
- **Variation Control**: Manage available sizes (S, M, L, XL, XXL) for every item.
- **Order Management**: Real-time order tracking with status updates (Pending, Out for Delivery, Delivered).
- **Auto-Cleanup**: Automated system to manage legacy order data and keep the dashboard fast.

## 🛠 Tech Stack

- **Frontend**: React.js + Vite
- **Styling**: Vanilla CSS + Tailwind-inspired Modern Design
- **Authentication**: Clerk (Role-aware Admin & User sessions)
- **Database**: Supabase (Postgres)
- **Real-time**: Supabase Postgres Subscriptions
- **Icons**: Lucide React
- **Date Management**: date-fns
